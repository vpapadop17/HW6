# Red-Black Tree

An implementation of a red-black tree along with a test program

## Files

- `RedBlackTree.h` — declares the `RBTNode` structure and `RedBlackTree` class.
- `RedBlackTree.cpp` — contains the red-black tree implementation.
- `RedBlackTreeTests.cpp` — contains the test cases and the test program's `main()` function.
- `Makefile` — provides commands to compile and run the tests.


## Compile and run


```bash
make
make run
```

Or compile and run in one command:

```bash
make try
```

The executable is named `rbt-tests`.
